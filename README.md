# AI Job Hunter

AI-powered job search assistant focused on the InfoJobs PMV.

This repository contains the foundation for a configurable job-search system that collects offers, stores search history, scores compatibility and presents relevant opportunities.

## PMV

- Portal: InfoJobs
- Configurable scan interval: 60 minutes by default
- Persistent offer/search history
- Configurable 0–100 matching score
- Direct navigation to the original offer
- No automatic application submission in the PMV

See `docs/pmv-specification.md` for the detailed specification.
